# 规范表达练习

一个单文件 HTML 网页工具，用于刻意练习「读材料 → 找点 → 归类 → 概括成句」的完整闭环。

🔗 [在线使用（GitHub Pages）](https://lllvernan-blip.github.io/formal-expression-practice/)

## 功能

- **概括训练**：四步向导（通读材料 → 找点 → 归类命名 → 成句 AI 批改）；内置来源型材料已移除，请在“我的材料”中提供自己有权使用的材料，再由 AI 生成题目
- **规范改写**：口语化表达转正式公文语体，题目和批改均由 AI 完成
- **我的材料**：粘贴或上传材料，由 AI 生成题目、切片、采分点和参考答案；长材料先按段落拆分选择练习片段，原始全文与 AI 加工结果分开保存；确认 AI 结果后才进入练习
- **AI 批改**：概括训练和规范改写均由 AI 进行语义级批改，AI 失败时不会伪装成离线结果
- **错题本**：主导航可直接进入，自动记录概括题和规范改写题的错误并支持只练错题；L3 自由划选的有效性在提交批改后统一判断并纳入错题记录，规范改写错题可恢复上次答案和批改结果
- **数据本地化**：练习记录、API 配置和用户材料均存储在浏览器 localStorage，不上传服务器

## 使用方法

### 在线

直接打开 [GitHub Pages](https://lllvernan-blip.github.io/formal-expression-practice/)，浏览器即可运行。

### 本地

```bash
git clone https://github.com/lllvernan-blip/formal-expression-practice.git
cd formal-expression-practice
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

或直接双击 `规范表达练习.html`。

## 接入 AI 批改

1. 点击「设置」
2. 填入你的 API 信息：
   - 支持 OpenAI 兼容接口（DeepSeek / 豆包 / 智谱 / 通义千问 等）
   - 需要填写：provider、API Key、模型名、接口地址
3. API Key 仅存储在浏览器 localStorage，不会上传到任何服务器

**建议使用单独的低额度 Key，并设置消费上限。**

材料生成请求会根据输出长度使用更长的等待时间；较长材料仍建议先在分段选择器中选择一个片段。

## 题库

概括训练不再内置来源型材料，支持导入个人材料和完整真题，由 AI 生成可练习结构。规范改写的题目和批改也全部由 AI 完成。

概括训练材料由你提供并经 AI 结构化生成；请确认你拥有材料的使用权。项目不再内置报道、政府文件或其他来源型材料。

## 技术说明

- 纯单文件 HTML（约 527KB），无外部依赖
- 内联 GSAP 3.15.0（开启动效，支持 reduced-motion 降级）
- 概括训练默认通过“我的材料”导入自有材料，再由 AI 生成题目；不提供内置来源题库
- 数据存储在 localStorage + 可选的 File System Access API 文件持久化
- 练习和检查均通过 OpenAI 兼容 API 直连；API 未配置时只显示配置提示，不进入离线替代流程
- L3 自由划选支持手机触摸文字选择；通读材料区域可独立滚动，长按选中文字后固定显示材料下方的加入按钮；提交时才由 AI 判断；错题本统一先加入待复盘选段，再由用户主动点击 AI 判断，让 AI 解释某段文字为什么应选或不应选
